# GeoAI Explorer — Technology Stack

Observed environment: Windows, Python 3.11.15, Conda environment `geoai`.

## Runtime stack

| Layer | Technology | Version / status | Purpose |
|---|---|---|---|
| Web server | Uvicorn | 0.46.0 | ASGI process on localhost |
| API framework | FastAPI | 0.141.1 | REST, validation, OpenAPI, static serving |
| Data validation | Pydantic | 2.13.5 | request constraints and intent validation |
| Numeric | NumPy | 2.4.4 | masks, class counts, indices |
| Raster GIS | Rasterio | 1.4.4 | windows, reprojection, masks, PNG/tile generation |
| Vector GIS | GeoPandas | 1.1.3 | GeoPackage fallback and exports |
| Geometry | Shapely | 2.1.2 | validation, intersection, area, distance |
| CRS | PyProj | 3.7.2 | EPSG:4326 ↔ EPSG:32647 transforms |
| Vector I/O | Pyogrio | 0.12.1, transitive | GeoPackage driver path |
| Image | Pillow | 12.2.0, transitive | previews and imagery output |
| PostGIS client | psycopg2-binary | 2.9.13 | optional PostgreSQL/PostGIS adapter |
| HTTP client | HTTPX | 0.28.1 | optional OpenAI / external HTTP calls |
| Object storage | boto3 | 1.43.98 | CDSE S3 session integration |
| 2D map | Leaflet | 1.9.4, vendored | Explore map |
| 3D map | MapLibre GL JS | 6.10.0, vendored | terrain/class tour |
| Motion | GSAP + ScrollTrigger | 3.15.0, vendored | cinematic scrolling |
| Frontend | HTML/CSS/vanilla JS | no build step | SPA and tool UI |

`Pillow` and `pyogrio` are installed but not directly pinned in `requirements.txt`; reproducible builds should pin all runtime-critical transitive packages after the thesis freeze.

## Storage and data formats

- GeoTIFF: PlanetScope RGBN, A7-T, NDVI, NDWI, COP30 DSM.
- GeoPackage: 155,199 clean A7-T polygons with RTree spatial index.
- SQLite: candidate human corrections.
- JSON: palette, knowledge base, metadata, cache records, manifests.
- NPZ: cached aligned Sentinel-2 bands/masks.
- PNG: map tiles and visualization previews.
- GeoJSON/GPKG/SHP/CSV/GeoTIFF: legacy analysis exports.

## Canonical paths

## Caching

- Categorical A7-T tiles: Python `lru_cache(maxsize=512)` and HTTP `public, max-age=86400`.
- Non-RGB static tile assets: HTTP `public, max-age=31536000, immutable`.
- ROI/external previews: no-store or private one-hour caching depending on endpoint.
- Sentinel-2 aligned cube: content-addressed local cache, schema `sentinel2-cube-v6-main-thread-jp2`.
- No global cache size quota, TTL, or eviction service was found for Sentinel-2.

## Reproducibility notes

- The frontend is directly served; there is no package-lock/build artifact to reproduce.
- Vendor JavaScript versions are locally fixed, but Google Fonts and basemap imagery are remote.
- Python dependency versions above are the inspected environment, not all strict pins.
- OpenAPI is generated by the current FastAPI application and should be archived for each thesis release.
